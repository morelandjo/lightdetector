
# Light Detector

A Minecraft NeoForge mod that adds a handheld light level detector tool. This is intended as a vanilla solution for people who want to know if the light level they are standing in can spawn mobs, there is an indicator when the light hits that level.


## Features

- A handheld item that detects the light level at the player's current location
- Similar to the Minecraft clock, the tool has a rotating dial, there is a mark on the dial that appears at the light level that spawns monsters.
- Made with redstone dust (center) and lapis lazuli (top, left, right, bottom)
